# Equitable Online Meta-Learning for AI-RAN Services (QMeL)

All experiments are done using a local MacBook Pro machine with Apple M1 Pro chip and 16 GB memory. Neural network experiments use MPS but also suitable and tested for CUDA. 
- Install required packages by using requirements.txt. 'pip install -r requirements.txt'
- Install torch and torchvision according to your specs, with CUDA or without.
- Experiments are explained more in detail in their respective scripts.
